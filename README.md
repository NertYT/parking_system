### 📂 Основные компоненты
* **`main.py`**: Ядро системы на Python. Отвечает за захват видеопотока RTSP, детекцию номеров через YOLOv8 и логику распознавания символов.
* **`index.php`**: Главная страница веб-интерфейса. Управляет выводом логов, формой добавления автомобилей и созданием бэкапов базы данных.
* **`style.css`** и **`script.js`**: Кастомная темная тема и скрипты для «живого» обновления данных без перезагрузки страницы.
* **`best.pt`** / **`best_rus.pt`**: Обученные веса моделей нейросети для детекции и OCR.

## 🛠 Инструкция по установке и запуску

Для работы системы требуется установленный **Python 3.8+**, **PHP 7.4+** (например, в связке с XAMPP или OpenServer) и база данных **MySQL**.

### 1. Подготовка базы данных
1. Откройте панель управления MySQL (phpMyAdmin).
2. Создайте новую базу данных с названием `parking_system`.
3. Импортируйте файл `parking_system.sql` в созданную базу данных.

### 2. Настройка веб-интерфейса
1. Разместите файлы проекта (`index.php`, `style.css`, `script.js`, `favicon.ico`) в корневую папку вашего локального веб-сервера (например, `htdocs` или `www`).
2. Откройте файл `db_config.php` и убедитесь, что учетные данные для подключения к MySQL (хост, логин, пароль) указаны верно.

### 3. Настройка нейросетевого модуля (Python)
1. Установите необходимые зависимости:
   ```bash
   pip install ultralytics opencv-python flask mysql-connector-python requests numpy
   ``` 

2. Убедитесь, что файлы моделей `best.pt` и `best_rus.pt` находятся в одной директории.

3. В файле `main.py` проверьте настройки в секции CONFIG:

RTSP_URL: ссылка на вашу IP-камеру или 0 для использования веб-камеры ноутбука.  

DB_CONFIG: данные для подключения к вашей базе данных MySQL.

4. Запуск системы

Запустите веб-сервер (Apache/Nginx) и MySQL.

Запустите скрипт распознавания:
python main.py

### 4. Откройте браузер и перейдите по адресу `http://localhost/название_папки`, чтобы открыть панель управления.

## 🚀 Основной функционал
* **Live-мониторинг**: Трансляция видеопотока с наложением рамок распознанных номеров в реальном времени.
* **Интеллектуальный OCR**: Алгоритм позиционной коррекции символов для точного распознавания российских гос. номеров.
* **Управление доступом**: Возможность добавления, редактирования и поиска автомобилей в базе данных.
* **Логирование**: Автоматическое сохранение скриншотов въезда в папку `snapshots/` и запись событий в БД.
* **Бэкапы**: Функция создания ZIP-архива с дампом базы данных и всеми файлами системы прямо из интерфейса.
